# 🎯 GUÍA RÁPIDA DE INICIO

## 📋 Resumen del Proyecto

Has creado una **aplicación web completa** para análisis de datos que incluye:

✅ **Análisis Exploratorio (EDA)** con 12,420 registros de datos de remuneración  
✅ **Modelo Machine Learning** Random Forest para predicción de Seniority  
✅ **API REST** con Flask para acceder a predicciones y análisis  
✅ **Frontend moderno** con JavaScript y CSS responsivo  
✅ **Visualizaciones** interactivas de resultados  

---

## 🚀 INSTALACIÓN EN 3 PASOS

### Paso 1: Instalar Dependencias
```powershell
cd "APP 2"
python setup.py
```

### Paso 2: Ejecutar Análisis (5-10 minutos)
```powershell
# Abrir VS Code o Jupyter
cd notebooks
jupyter notebook data_analysis.ipynb

# Ejecutar todas las celdas:
# Menú: Cell > Run All (o Ctrl+Shift+Enter)
```

**Esto generará:**
- ✓ Modelo Random Forest entrenado
- ✓ 7 gráficas de análisis
- ✓ Archivos JSON con resultados

### Paso 3: Iniciar Aplicación (2 terminales)

**Terminal 1 - Backend:**
```powershell
cd backend
python app.py
# Esperar: "Servidor disponible en: http://localhost:5000"
```

**Terminal 2 - Frontend:**
```powershell
cd frontend
python server.py
# Esperar: "Servidor iniciado en: http://localhost:8080"
```

**Abrir navegador:**
```
http://localhost:8080
```

## 📊 Características de la Aplicación

### 📈 Dashboard
- **Metrics**: Accuracy, Precision, Recall, F1-Score
- **Dataset Info**: Total de registros, features, split train/test
- **Seniority Distribution**: Gráfico de distribución de clases

### 🔍 Análisis Exploratorio (EDA)
- Distribuciones de edad, género, dedicación, seniority
- Matriz de correlación entre variables
- Análisis de valores faltantes

### 🤖 Modelo Random Forest
- **Configuración**: 200 árboles, profundidad máxima 15
- **Feature Importance**: Qué variables son más importantes
- **Métricas**: Matriz de confusión, accuracy, F1-score
- **Performance**: Gráficas de evaluación

### 🎯 Predicción en Vivo
- Formulario para ingresar datos de un trabajador
- **Resultado**: Predicción del seniority
- **Confianza**: Porcentaje de certeza
- **Probabilidades**: Desglose por clase

### 📸 Galería de Gráficas
- Descargables en alta resolución (300 DPI)
- Todas las visualizaciones generadas

---

## 💼 Features y Columns Principales

**Variables Predictoras (9 features):**
- Edad
- Años de experiencia
- Antigüedad en empresa actual
- Años en puesto actual
- Personas a cargo
- Salario bruto (pesos)
- Salario neto (pesos)
- Salario bruto (dólares)
- Salario neto (dólares)

**Variable Objetivo:**
- **Seniority**: Junior, Semi-Senior, Senior

## 🔌 API Endpoints

| Método | Endpoint | Descripción |
|--------|----------|-------------|
| GET | `/api/health` | Verificar conexión |
| GET | `/api/analysis-info` | Información general |
| GET | `/api/model-metrics` | Métricas del modelo |
| GET | `/api/feature-importance` | Importancia de features |
| GET | `/api/dataset-info` | Información del dataset |
| GET | `/api/model-info` | Configuración del modelo |
| POST | `/api/predict` | Realizar predicción |
| GET | `/api/available-graphics` | Listar gráficas |
| GET | `/api/graphics/{filename}` | Descargar gráfica |

## 🐛 Solución Rápida de Problemas

| Problema | Solución |
|----------|----------|
| "Backend no disponible" | Ejecutar `python app.py` en backend |
| "No se ve el frontend" | Ejecutar `python server.py` en frontend |
| "No hay gráficas" | Ejecutar notebook completo |
| "Puerto 5000/8080 en uso" | Cambiar puerto en app.py o server.py |
| "ModuleNotFoundError" | Ejecutar `python setup.py` para instalar dependencias |

## 📈 Ejemplo de Predicción

**Input:**
```json
{
    "tengo_edad": 30,
    "Años de experiencia": 5,
    "antiguedad_en_la_empresa_actual": 2,
    "Años en el puesto actual": 2,
    "cuantas_personas_tenes_a_cargo": 0,
    "ultimo_salario_mensual_o_retiro_bruto_en_pesos_argentinos": 1000000,
    "ultimo_salario_mensual_o_retiro_neto_en_pesos_argentinos": 850000,
    "sueldo_bruto_en_dolares": 1000,
    "sueldo_neto_en_dolares": 850
}
```

**Output:**
```json
{
    "status": "success",
    "prediction": "Semi-Senior",
    "confidence": 0.85,
    "probabilities": {
        "Junior": 0.10,
        "Semi-Senior": 0.85,
        "Senior": 0.05
    }
}
```
