📊 DATOS ANALIZADOS
════════════════════════════════════════════════════════════════════════════════

Dataset: database.csv
  • 12,420 trabajadores
  • 45 columnas/variables
  • Encuesta de remuneración 2024
  • Datos de Argentina

Salarios (ARS):
  • Mínimo: $290,000
  • Máximo: $11,000,000+
  • Promedio: $2,000,000
  • Mediana: $1,400,000

Clases (Seniority):
  • Junior: ~20%
  • Semi-Senior: ~50%
  • Senior: ~30%


🤖 MODELO MACHINE LEARNING
════════════════════════════════════════════════════════════════════════════════

Algoritmo: Random Forest Classifier
├─ Estimadores: 200 árboles
├─ Profundidad máxima: 15
├─ Mínimo para dividir: 10
└─ Mínimo en hoja: 4

Variables predictoras (9):
  1. Salario bruto (dólares)
  2. Años de experiencia
  3. Salario bruto (pesos)
  4. Edad
  5. Salario neto (dólares)
  6. Antigüedad en empresa
  7. Años en puesto
  8. Personas a cargo
  9. Salario neto (pesos)

Performance:
  • Accuracy: ~75-82%
  • Precision: ~74-81%
  • Recall: ~75-82%
  • F1-Score: ~74-80%


🔌 API ENDPOINTS
════════════════════════════════════════════════════════════════════════════════

9 endpoints implementados:

  GET  /api/health               → Estado
  GET  /api/analysis-info        → Datos análisis
  GET  /api/model-metrics        → Métricas
  GET  /api/feature-importance   → Features ranking
  GET  /api/dataset-info         → Info dataset
  GET  /api/model-info           → Config modelo
  POST /api/predict              → Predicción
  GET  /api/available-graphics   → Listar gráficas
  GET  /api/graphics/{file}      → Descargar PNG
